# Scouternas logotyp och symbol

Filerna i den här katalogen är **Scouternas officiella logotyp och scoutsymbol**. De är hämtade från Scouternas grafiska profil:
<https://www.scouterna.se/scout-ledare-kar/kommunicera/grafisk-profil/>

| Fil | Användning |
|---|---|
| `scouterna_white_RGB.svg` | Vit logotyp på blå bakgrund (toppraden) |
| `scouterna_blue_RGB.svg` | Blå logotyp på ljus bakgrund |
| `scouterna_tagline_white_RGB.svg` | Logotyp med tagline (inloggningssidan) |
| `Scoutsymbolen_rgb.png` | Scoutsymbolen (favicon, app-ikon) |

**Varumärke:** logotypen och scoutsymbolen är varumärken som tillhör Scouterna. De omfattas **inte** av projektets MIT-licens och används enligt Scouternas grafiska profil. Filerna får inte ändras, till exempel genom att färg eller proportioner byts.
